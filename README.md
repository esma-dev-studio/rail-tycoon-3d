# 🚆 でんしゃタイクーン3D (Rail Tycoon 3D)

せんろを つくって、電車を はしらせて、お客さんを はこぼう！
小学2年生から遊べる、Transport Tycoon 風の3D鉄道経営ゲームです。ブラウザだけで動きます。

![tech](https://img.shields.io/badge/React-18-61dafb) ![tech](https://img.shields.io/badge/Three.js-0.161-000) ![tech](https://img.shields.io/badge/TypeScript-strict-3178c6) ![tech](https://img.shields.io/badge/Vite-5-646cff)

## あそびかた

1. **🛤 せんろ** をおして、じめんを 2かい クリック → せんろが できるよ（1マス 100円）
2. **🚆 電車** をおして、つないだ 町を 2つ クリック → 電車が はしりだすよ（1だい 5,000円）
3. 電車が お客さんを はこぶと **お金が もらえる**！（町の上に「+○円」って出るよ）
4. お客さんが たくさん まってたら、ろせんを クリックして **電車を ふやそう**
5. **💥 こわす** で せんろを こわせるよ（お金が はんぶん もどる）

## 開発

```bash
npm install
npm run dev      # 開発サーバ (http://localhost:5182)
npm run build    # 本番ビルド (dist/)
npm run preview  # ビルド結果のプレビュー
```

## 設計メモ

- **状態の分離**: 資金・路線・線路・ミッションなどの離散的な状態は Zustand ストア（`src/store`）が持ち、列車の連続的な位置は React の外の可変シングルトン（`src/sim/simInstance.ts`）が持つ。列車の移動は `useFrame` から直接メッシュを更新し、毎フレームの React 再描画を避けている。UI 表示は約 5Hz で `revision` を更新して追従する。
- **シミュレーションの独立性**: 乗客発生・列車の移動と乗降・運賃計算・ミッション判定などのロジックは Three.js / React に依存しない純粋な関数（`src/sim`, `src/utils/grid.ts`, `src/data/missions.ts`）。Node 単体でも検証できる。
- **経路探索**: 路線開設時は敷設済みエッジのグラフ上で BFS を行い、最短の駅間経路を求める（`src/sim/pathfinding.ts`）。
- **グリッド世界**: 16×16 のグリッド。線路はノード間の無向エッジ集合として保持し、敷設はマンハッタン（L字）経路で行う。
- **子ども向け設計**: 全UIをひらがな中心・わかち書きで表記。お金は「1マス100円」などキリのいい数字に統一し、敷設前に「○マス＝○円」を表示。目的地到着時は「+○円」が町の上に浮かんで、お金が増える理由が見えるようにしている。
