# でんしゃの町 — Railway Garden

小学2年生が「自分の鉄道で町を育てる」3Dまちづくりゲームです。
[公開ページ](https://esma-dev-studio.github.io/rail-tycoon-3d/)

## 遊び方

1. 「せんろ」で町を2つ選び、線路と電車をつくる。
2. 電車が人を目的地へ届けると、お金がたまり、町が育つ。
3. 「町づくり」で町のゆめを選び、工事を始める。
4. その町へ必要な人数が到着したら「かんせいさせる」を押す。
5. 地図に施設が建ち、新しい駅が開く。さらに線路を延ばす。

目標は常に1つ。報酬は自分で受け取り、次の目標へ進みます。
時間制限、借金、ゲームオーバーはありません。

## 今回のリニューアル（V7）

- 地図と手帳を分けた、ジオラマ＋アイボリー／深緑の画面。
- 操作は「せんろ・町づくり・電車・手帳」の4つに集約。
- 公園、図書館、市場、音楽ホール、水族館、キャンプ場、空港デッキ、灯台の8つの建設計画。
- 工事代は一度だけ。工事開始後の到着人数で進み、完成時に賞金と3D施設を獲得。
- 施設1／3／5個の完成で、こもれびの森／そらいろ空港／しおかぜ海岸が順に開放。
- 工事中の町へのお出かけ需要が増え、完成した施設も観光客を呼び続ける。
- 3章15ミッションの後は、町を順番に巡る12人ずつの「おでかけ便」。
- 手帳に8つの施設スタンプ、発見した駅、運んだ人数を記録。
- 長さの改良で車両が3→4→5両に。各車両が線路に沿って曲がる。
- 大きなボタン、主要な難しい名称の読み仮名、キーボード操作できる駅名。
- 旧V5／V6データを引き継ぎ。ページを閉じる直前の操作も保存。
- 保存できないブラウザでは警告。最初の線路を作る前の使い切りを防止。
- 外部フォント、外部3D素材、解析ツール、APIキー不要。

## 電車のしくみ

電車はどちらの方向にも往復し、途中の駅でも乗降します。
A—BとB—Cがあれば、Cへ行く乗客はBで自動的に乗り換えます。
中央の町を必ず通るルールはありません。
行ける町だけを目的地にし、未開放の駅に客が発生することはありません。

町はレベル6まで、各路線の長さ・速さはレベル3まで育ちます。
追加列車と改良の費用・効果は「電車」で確認できます。
新しい観光駅が開いても、元の5町を対象とする章目標は変わりません。

## 保存

進行状況は同じブラウザ・同じ公開URLのlocalStorageに保存します。
再訪時は電車が駅から再スタートします。乗車中・待機中の乗客は再生成されます。
町、お金、路線、改良、工事、完成した施設、章の進行は残ります。
別の端末やブラウザへは自動同期されません。

## 開発と検証

Node.js 22以降を推奨します。

```sh
npm ci
npm run typecheck
npm run verify:network
npm run verify:growth
npm run verify:adventure
npm run dev
npm run build
```

- network: 双方向経路、乗り換え、接続判定
- growth: 3章、改良費と効果、町の成長
- adventure: 実シミュレーションの往復、二重購入／報酬防止、建設、駅の開放、保存・旧データ移行
- browser: PC／390pxの操作と画面、施設完成、再読み込み、ダイアログ、実行時エラー

ブラウザ検証はPlaywrightとMicrosoft Edgeを使用します。
Playwrightが別の場所にある場合は、そのnode_modulesを `RAIL_TEST_NODE_MODULES` に指定してください。
開発サーバー（127.0.0.1:5182）を起動して `npm run verify:browser` を実行します。
テストは独立したブラウザ環境で行い、ユーザーの保存データには触れません。
検証画像はGit管理対象外の `artifacts/` に出力します。
