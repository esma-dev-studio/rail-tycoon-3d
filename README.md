# 🚆 わくわく でんしゃの町

町を2つ選ぶだけで線路と電車が完成する、小学2年生向けの3D鉄道・町づくりゲームです。
ブラウザだけで動き、続きは自動保存されます。

## 遊びの中心

1. **新しいせんろ**を押して、町を2つ選ぶ
2. 値段と残るお金を見て、路線を作る
3. 最初から3人のお客さんを乗せた電車が出発する
4. お客さんが着くと、お金と町の成長が増える
5. 貯めたお金で町にプレゼントを置く
6. 5つの駅スタンプと6つのおねがいを集める

## 小学2年生向けにしたこと

- 主要操作は「町を2つ選ぶ」だけ
- ひらがな中心・短い文・大きなボタン
- 車掌の「てつくん」が次の1手だけを案内
- 長く待たせず、最初の路線から必ず収入が発生
- 失敗やゲームオーバーではなく、あといくら必要かを表示
- 上級操作は「じゆう」の中に分離

## 楽しさの循環

`線路を作る → 電車を見る → 人が笑顔になる → お金が増える → 町を飾る → 次の町へ広げる`

町の飾りは購入後に3Dマップへ実際に現れます。

- お花ばたけ
- 大きな時計
- きらきら噴水
- ミニ観覧車
- にじいろゲート
- ほしぞらタワー

## 開発

```bash
npm install
npm run dev
npm run typecheck
npm run build
```

## 技術

- React 18 / TypeScript / Zustand
- Three.js / React Three Fiber / drei
- Vite
- 外部3Dモデルなし。町、電車、線路、飾りはプリミティブ形状で構成

デプロイはGitHub Actionsの`.github/workflows/deploy.yml`が`main`へのpushを検知して実行します。
